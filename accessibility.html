Accessibility

The Staph Aureus Experience™ is a digital gallery of Polaroid-style collages by Alice van Rooyen / Apple Violet Robot.

The gallery presents six randomly ordered Polaroids at a time. This avoids creating a single fixed route through the work.

Image descriptions

The project includes a separate plain-text image descriptions page. This provides each Polaroid caption and a short visual description in a format that can be read by browser read-aloud tools and screen readers.

Keyboard controls

  • Right arrow: show the next six Polaroids
  • Left arrow: show the previous six Polaroids
  • Tab: move through available page controls and links
  • Esc: close an enlarged image

Image enlargement

Select any Polaroid to enlarge it. This may make the image and handwritten caption easier to read.

Content note

The work includes references to hospitalisation, sepsis, infection, medical treatment, bodily vulnerability, bodily fluids, intimate care, and serious illness.
